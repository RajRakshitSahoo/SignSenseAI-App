# ASL Hand Shape Reference Guide

A quick reference for all 29 signs supported by SignSense AI.

## Letters A–Z

| Letter | Hand Shape Description |
|--------|----------------------|
| **A** | Closed fist, thumb resting alongside the index finger (not over fingers) |
| **B** | All four fingers extended upward together, thumb folded across palm |
| **C** | All fingers curved in a C-shape, thumb opposite fingers |
| **D** | Index finger pointing up, thumb and middle finger touch forming a circle |
| **E** | All fingers curled, fingertips touch the thumb |
| **F** | Index finger and thumb touch (OK-like), other three fingers spread up |
| **G** | Index finger and thumb point horizontally sideways, hand turned |
| **H** | Index and middle fingers extended horizontally together, side by side |
| **I** | Only the pinky finger extended upward, others curled |
| **J** | Like I, but trace a J shape in the air (pinky draws the letter) |
| **K** | Index and middle fingers up and spread, thumb between them |
| **L** | Index finger pointing up, thumb pointing out — forms an L shape |
| **M** | Three fingers (index, middle, ring) folded down over the thumb |
| **N** | Two fingers (index, middle) folded down over the thumb |
| **O** | All fingers and thumb curve to meet, forming an O shape |
| **P** | Like K but hand tilted downward |
| **Q** | Like G but hand tilted downward |
| **R** | Index and middle fingers crossed over each other |
| **S** | Closed fist with thumb resting over the fingers |
| **T** | Thumb tucked between index and middle finger |
| **U** | Index and middle fingers extended upward close together |
| **V** | Index and middle fingers extended upward spread apart (peace sign) |
| **W** | Index, middle, and ring fingers extended upward spread apart |
| **X** | Index finger bent/hooked, others curled |
| **Y** | Thumb and pinky extended out, other fingers curled (shaka / hang loose) |
| **Z** | Index finger extended, traces a Z shape in the air |

## Special Signs

| Sign | Hand Shape Description |
|------|----------------------|
| **space** | Open flat palm facing camera — adds a space between words |
| **del** | Thumbs-down gesture — deletes the last character |
| **nothing** | No hand visible, or a neutral resting position |

## Tips for Best Recognition

1. **Hold each sign steady** for about 1 second — the stability bar shows progress
2. **Face your palm toward the camera** — the model works best with the palm visible
3. **Keep your hand in the center** of the camera frame
4. **Good lighting** helps — avoid bright backlighting
5. **Lower the confidence threshold** (slider) if signs aren't being detected
6. **Use the keyboard input** bar as a fallback for any letters that are hard to sign
